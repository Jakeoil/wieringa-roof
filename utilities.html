Favicon

A tab icon is sixteen pixels: silhouette and color survive, detail does not. An unfolding makes a good subject for exactly that reason — it is sparse. Queen at generation 1 fills only 47% of its own bounding box, and that spidery outline still reads when the rhombi no longer do.

Use it in this tab swaps this page's own icon, which is the only honest preview — a favicon rendered at 16 px by the browser looks different from a 16 px image on a page. To make it the site's icon, download it as favicon.svg into the project root; every page already links to that name.
