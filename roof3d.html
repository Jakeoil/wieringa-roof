The roof surface in three dimensions — a prototype to look at before committing paper to it.

Not built yet. This page is a placeholder pending three.js being vendored into the project.

How it will work

This page is close to free. The existing generator already computes a correct vertex index for every rhomb corner, and height is nothing more than index · s/√5 — so the 3D surface is the same rhomb data with one extra coordinate. No new geometry at all.

One thing to expect: total relief is only 1.342 s, so from a low camera angle the roof looks almost flat. A vertical-exaggeration slider will be needed before the hills and dales read properly.

three.js will be vendored locally as vendor/three.module.js with an import map, rather than pulled from a CDN, so the site keeps working offline like the rest of it.
